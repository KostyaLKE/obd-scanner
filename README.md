# OBD Сканер

Android-приложение для диагностики автомобиля через Bluetooth-адаптер **ELM327**.
Интерфейс на русском. Разрабатывается под Skoda Fabia (дизель, 2000–2010), но работает с любой
машиной с OBD-II / EOBD.

## Возможности

- **Ошибки**: сохранённые (сервис 03), ожидающие (07), постоянные (0A, только CAN).
  - расшифровка на русском (~420 стандартных кодов + известные коды VAG P1xxx);
  - номер в формате VAG (например P1557 → **17965**), как в VCDS и на форумах;
  - возможные причины для частых неисправностей дизелей VAG;
  - **стоп-кадр**: параметры двигателя в момент появления ошибки;
  - стирание ошибок с предупреждением;
  - отчёт: «Поделиться» и сохранение в истории.
- **Датчики**: обороты, наддув, ДМРВ, температуры, педаль, напряжение и т.д.;
  минимум/максимум, мини-график, избранные параметры для быстрого опроса.
- **Готовность**: мониторы самодиагностики (дизель/бензин), Check Engine, пробег и время после
  стирания ошибок. Полезно при покупке подержанной машины.
- **Авто**: VIN, стандарт OBD, протокол, версия адаптера, напряжение.
- **Журнал**: обмен с адаптером и ручной ввод команд (AT и OBD).
- **Демо-режим**: эмулятор Fabia 1.9 TDI для проверки без машины.

## Установка

1. Откройте [последний релиз](../../releases/tag/latest) и скачайте `obd-scanner.apk`.
2. Разрешите установку из этого источника (Android спросит сам).
3. Вставьте адаптер в разъём OBD, включите зажигание.
4. Выполните сопряжение в настройках Bluetooth телефона (PIN `1234` или `0000`).
5. Откройте приложение и выберите адаптер.

Каждый пуш в `main` собирает новый APK (GitHub Actions). Он ставится поверх старого:
подпись постоянная, ключ лежит в `app/obd-scanner.jks`. Это личное приложение, не для Google Play.

## Ограничения

- Через стандартный OBD-II виден в основном **блок двигателя**. ABS, подушки, комфорт на Fabia I
  работают по протоколу VAG KW1281, а дешёвый ELM327 его не поддерживает.
- У дизелей до ~2004 года поддержка EOBD могла быть неполной: часть данных машина может не отдавать.

## Разработка

```
./gradlew testDebugUnitTest   # тесты разбора ответов + сценарий на эмуляторе
./gradlew assembleDebug
python3 tools/gen_dtc.py      # пересобрать базу ошибок (assets/*.tsv)
```

Структура: `elm/` — Bluetooth и ELM327, `obd/` — протокол OBD-II, ошибки, датчики,
`ui/` — экраны на Jetpack Compose.
